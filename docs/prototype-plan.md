# 프로토타입 상세안 v0.2

작성일: 2026-10-31. [통합 기획](game-design.md)의 카드·유닛·채굴·제작을 함께 검증하기 위한 추천안입니다. **선택된 규칙을 반영한 계획이며 전체 제작 목록의 구현 승인이나 밸런스 검증 완료를 의미하지 않습니다.** 상태는 [결정 기록](decisions.md)을 따릅니다. 단일 광석·고정 덱의 이전 수치는 [v0.1 보관본](archive/prototype-plan-v0.1.md)에 유지합니다.

2026-11-03 사용자 선택을 반영합니다. 지상 탑다운·지하 단면을 전투·정비 단계에 따라 전환하며, 기본 덱 8장·손패 4장·동일 카드 반복 소환·기본 6슬롯·생존 HP 유지로 검증합니다. 건물 카드 설치·동종 강화·타종 교체와 에너지 손패 교환을 사용하고 광물은 도구·공통 장비, 금은 슬롯 강화·유닛 카드 3택1 모집에 씁니다.

채굴은 수작업 보드 1개·정비당 5굴착·추리 시간 제한 없음·4방향 갱도·최초 둥지 8이웃 숫자입니다. 안전한 시작 구역과 무료 스캔 1회를 제공하고, 스캔은 경계 1칸의 광물·둥지·숫자만 공개하며 굴착·자원 지급과 구분합니다. 현재 이동·굴착이 끝나면 남은 굴착을 포기하고 정비를 끝낼 수 있습니다.

모집은 후보 확인 무료·덱 교체 확정 시 결제·취소 무소모·같은 후보 유지입니다. 획득 시 1대1 교체로 활성 8장을 유지하고 정비 후 손패에 최근 획득 1장을 우선 포함합니다. 가격·레시피·후보 종류별 콘텐츠·회복량·안전 구역 크기·첫 공세 준비와 실제 환경은 [규칙 선택지](rule-options.md)에서 정합니다.

남은 운영 규칙과 전투 초깃값은 [첫 3웨이브 플레이 사양](first-playable-spec.md)의 P-01~P-10에 통합했습니다. 이 문서는 연결판의 범위·목표를, 플레이 사양은 아직 확정하지 않은 세부 추천값을 관리합니다. 기존 선택과 새 추천을 구분하며 실제 플레이 검증은 남아 있습니다.

## 검증 목표

**카드로 방어 → 채굴로 광물 확보 → 도구 또는 방어에 투자 → 다음 전투에서 차이 확인**의 흐름을 3웨이브로 연결합니다. 유닛이 적을 붙잡고 건물이 처리하는 조합, 새 카드 획득·교체도 같은 판에서 확인합니다.

최종 웨이브 생존이 승리 조건이며 거점 체력이 0이면 패배합니다. 심층 코어는 선택 보상이므로 첫 연결판의 승리 조건으로 추가하지 않습니다.

도감의 실제 영구 저장·자유 시작 편성, 룬·진화, T3·토륨·대형 지원 공격은 연결판 결과 뒤 확장 범위를 결정합니다. 첫 검증의 순서 제안이며 해당 아이디어를 폐기한 결정이 아닙니다.

[유저 몬스터 제작실·샌드박스](user-content-plan.md)는 후속 검토 범위입니다. 기본 몬스터의 정의·실행 상태 분리는 유지하되 에디터·사용자 팩 공유·스크립트 실행은 첫 연결판에 추가하지 않는 제안입니다.

## 카드 덱과 에너지

첫 검증의 기본 덱 8장·손패 4장과 도감 선택 UI 후속은 확정입니다. 아래 종류별 장수·코스트는 콘텐츠 가안입니다. 기본 4+선택 4·점수는 후속 도감 편성에서 별도로 검토합니다.

| 카드 종류 | 시작 장수 | 행동 분류 | 맡는 역할 |
| --- | --- | --- | --- |
| 연사탑 | 3 | 건물 | 단일 표적 지속 화력 |
| 포격탑 | 1 | 건물 | 저지 지점의 범위 피해 |
| 경비병 | 2 | 유닛 | 경로에서 적 저지 |
| 서리 | 1 | 마법 | 통과한 적의 감속 |
| 폭발 | 1 | 마법 | 지정 범위의 즉시 피해 |
| 전격탑 | 0 | 건물 | 확장 보상으로 얻는 연쇄 공격 |
| 사수 | 0 | 유닛 | 금 모집 후보, 원거리 지속 화력 역할 제안 |
| 폭파병 | 0 | 유닛 | 금 모집 후보, 범위 화력 역할 제안 |

시작은 5종 8장이고 모집용 유닛 2종을 더해 콘텐츠는 8종인 제작 제안입니다. 시작 덱 장수 8과 콘텐츠 종류 수 8은 다른 값입니다. 초기 카드는 일반 등급·편성점수 1로 가정하면 출발 합계는 8로 10 이하를 만족합니다. 희귀도와 전투 코스트를 같게 취급하지 않습니다.

지상 확장 보상은 전격탑 한 종류를 제안합니다. 획득 시 기존 1장과 교체하고 활성 8장을 유지합니다. 일반 확장 보상 넘김은 미정이며 금 모집은 교체 확정 시 결제·취소 무소모·동일 후보 유지로 정했습니다. 확장 보상을 여러 후보로 늘리는 것은 후속이며 금 모집의 유닛 카드 3택1과 구분합니다. 여러 보상 시스템이 같은 획득을 두 번 지급하지 않게 합니다.

금 모집 자체는 전투 에너지·필드 유닛 수·사용 슬롯을 바꾸지 않습니다. 선택한 카드를 덱에 넣는 방식과 실제 소환은 별도 단계입니다.

정비 후 손패는 현재 활성 덱에서 4장으로 재구성하고 최근 획득 1장을 우선 포함합니다. 첫 손패에 건물·경비병·서리를 우선 배분하는 것은 별도 제안입니다. 교체한 카드 종류가 덱에 남아 있지 않으면 기존 설치물의 동일 카드 강화 기회가 줄어듦을 안내하는 안입니다. 이미 배치한 병력을 교체만으로 제거·회복시키지 않습니다.

에너지 최대 10·전투 시작 6·2.5초당 1 회복, 카드별 비용·피해·체력·강화 상한은 [플레이 사양 P-01~P-04](first-playable-spec.md)에 추천값으로 묶었습니다. 정비 중 회복·다음 공세 잔액 이월은 허용하지 않는 안이며 기존 v0.1 수치를 일괄 채택하지 않습니다.

## 유닛과 건물

- 같은 유닛 카드로 여러 명을 소환할 수 있고 전장 전체 슬롯으로 제한합니다. 카드 2장이 최대 유닛 2명을 뜻하지 않습니다.
- 기본 6슬롯·첫 유닛당 1슬롯이며 금 같은 재화 광물로 슬롯 상한을 업그레이드할 수 있습니다. 가격·최종 상한·첫 연결판 강화 횟수는 미정입니다.
- 지정 위치 자동 교전·저지는 확정이며 저지 수 2는 실험값입니다. 초과 적 이동과 사망 시 저지 해제를 검증합니다.
- 생존 유닛과 남은 HP·점유 슬롯을 다음 웨이브에 유지합니다. 정비에서 재료로 선택 치료하고 무료 재배치할 수 있으며 재배치 자체는 개체·HP·슬롯을 보존합니다. 건물 유지는 기존 추천안입니다.
- Q-06=A로 건물 카드는 빈 패드 설치·동종 강화·다른 종류 교체에 사용하고 전투 에너지로 손패를 교환합니다. 비용·강화 상한·교체 손실·교환 순서는 미정입니다.
- Q-10=A로 개별 타워 레벨은 에너지, 도구·공통 장비는 광물, 룬은 후속 공격 방식 분기로 역할을 구분합니다. 레벨을 올린 개체와 같은 종류의 다른 타워·카드는 구분합니다.

Q-04=A로 첫 전장은 고정 적 경로·건물 패드·유닛 배치 칸을 사용합니다. 배치로 경로를 다시 계산하지 않고 저지는 일반 이동 충돌·범위 공격 판정과 구분합니다. 이후 자유 배치·경로 재계산과 지하 중력·사다리로 전환할 수 있도록 지형·점유·설치 검사·경로 계산을 나누는 설계는 [아키텍처](architecture.md)를 따릅니다. 해당 후속 기능 자체는 첫 검증에 구현하지 않습니다.

## 채굴과 제작

정비당 5굴착·추리 시간 제한 없음과 최초 둥지 배치의 주변 8칸 수로 숫자 고정은 확정입니다. 안전한 시작 구역·정비당 무료 스캔 1회·남은 굴착을 포기한 조기 정비 종료도 확정했습니다. 스캔은 접근 가능한 갱도 경계의 미굴착 1칸에서 광물·둥지 유무·숫자를 공개하고 굴착 횟수·자원을 바꾸지 않습니다. 정비 종료는 현재 이동·굴착 완료 뒤에만 가능하며 미사용 굴착을 포기합니다. 숫자 0은 연결 영역과 경계 숫자만 연쇄 공개하고 실제 굴착·광물 획득은 별도로 합니다. 스캔은 선택 1칸만 공개합니다. 안전 구역 크기는 수치 초안으로 제안합니다. 광부는 열린 갱도를 상하좌우로 이동해 선택한 타일 옆의 작업 위치에서 한 번 굴착합니다. 대각선 정보가 이동 가능성을 뜻하지 않으며 현재는 중력·사다리 제작을 요구하지 않습니다.

| 제작 | 필요한 재료의 역할 | 결과 |
| --- | --- | --- |
| 강화 드릴 T2 | 현재 T1으로 채굴 가능한 철·구리 | 수정 광맥·단단한 암반 접근 |
| 경비병 장갑 | 도구 제작과 겹치는 철을 소비 | 이번 판 경비병의 생존 시간 증가 |
| 전격 코일 | T2로 얻는 수정과 기본 재료를 소비 | 이번 판 전격탑의 화력 증가 |

Q-14의 추천은 장갑이 최대 체력만 늘리고 저지 수·별도 방어력은 바꾸지 않는 방식입니다. 생존 유닛의 최대 체력은 늘리되 현재 HP는 보존하고 새 소환은 새 최대 체력으로 시작하는 후보입니다. 치료는 정비 중 재료를 쓰는 별도 동작으로 확정했고 재료 종류·회복량은 미정입니다. 슬롯 강화와 유닛 뽑기는 금 재화를 사용하므로 제작 광물·금 광맥의 굴착 선택과 가격을 함께 계산해야 합니다.

재료 수량과 비용은 미정입니다. Q-16=A로 수작업 보드 1개부터 검증하고 자동 생성은 후속으로 정했습니다. 배치·가격과 예시 경로의 계산은 [첫 보드·경제 초안](first-board-economy.md)에 있으며 실제 게임에서의 진행·전투 균형 검증과 구분합니다. 수작업 보드에서 각 레시피 재료까지의 거리·굴착 수·둥지 위험을 검증합니다. 첫 정비에서 T2를 제작하고 두 번째 정비에서 수정을 캐 전격 코일을 제작할 수 있는 경로·수량을 보장해야 합니다. 코일은 전격탑을 활성 덱에 보유한 경우 제작 가능하며 이번 판 기존·신규 전격탑에 적용하는 Q-20 추천안입니다.

3웨이브 안에 상위 자원의 방어 용도가 있어야 도구 투자의 가치를 비교할 수 있습니다. 첫 정비의 장갑으로 즉시 생존력을 높이는 경로와 T2에 투자해 최종 웨이브의 전격 화력을 높이는 경로를 같은 조건에서 관찰합니다.

도구 투자와 장갑 투자를 같은 맵·공세에서 비교합니다. 잘못된 등급·접근 불가 타일·재료 부족에는 작업이나 광물을 소비하지 않습니다. 도구 제작의 보상이 굴착 시간 단축만으로 끝나지 않아야 합니다.

기존 광석 보상·룬 구매·수리 가격은 적용하지 않습니다. 기본 재료 수입·광맥 수확량·수리 필요 여부와 비용은 새 경제 기준으로 함께 정합니다.

## 한 판의 순서

1. 시작 안내와 기본 덱을 확인하고 첫 전투를 시작합니다.
2. 건물·경비병·마법으로 1웨이브를 막습니다.
3. 정비에서 채굴·도구·장갑·금 모집·치료·재배치를 비교합니다. 모집과 덱 편집은 정비 중 오갈 수 있게 제안합니다.
4. 다음 적 구성과 둥지로 예약된 추가 공세를 확인하고 2웨이브를 시작합니다.
5. 두 번째 정비에 진입하면 다음 공세를 예고하고 지상 확장·전격탑 보상·덱 교체를 먼저 처리합니다.
6. 채굴·제작·금 모집·덱 편집·치료·재배치를 이어갑니다. T2를 제작했다면 수정에 접근할 수 있어야 하며 전격탑을 보유했고 재료가 충분하면 코일을 제작합니다. 마지막에 준비 확인과 손패 4장 재구성·최근 획득 우선 처리를 한 번 수행하고 다음 공세를 시작합니다.
7. 3웨이브를 막으면 승리하고 결과·재시작을 확인합니다.

Q-01=A로 지상 확장은 정해진 웨이브 뒤 열리며 첫 검증은 2웨이브 뒤 1회입니다. 지하 깊이·유적 발견을 필수 해금 조건으로 두지 않습니다. 확장 후보는 긴 경로와 적은 설치 지점, 짧은 경로와 많은 설치 지점으로 비교하는 제안입니다. 정확한 타일 수·설치 지점 수는 현재 전장 크기·사거리와 함께 정합니다. 기존 경로·타워는 유지합니다.

실제 둥지 굴착은 즉시 광부 피해 없이 다음 공세에만 추가 적을 한 번 예약·예고합니다. 적 수·역할은 저지와 범위 화력에 맞춰 재조정하며 v0.1의 둥지당 일반 적 6이나 웨이브 편성을 자동 채택하지 않습니다.

## 완료 기준

- 처음 플레이한 사람이 카드 3분류와 저지 초과 이동을 이해할 수 있음.
- 같은 공세에서 배치·마법·제작 선택의 결과 차이가 관찰됨.
- 도구 등급, 필요한 재료와 도달 가능한 다음 광맥을 확인할 수 있음.
- 카드 획득 시 1대1 교체로 활성 8장을 유지하고 다음 공세의 손패 4장에 유효한 최근 획득 1장을 우선 포함함.
- 둥지·굴착·제작·정산이 중복 입력에도 한 번만 적용됨.
- 최종 공세 생존과 거점 파괴로 각각 결과 화면에 도달함.
- 웨이브 전환에서는 생존 ID·현재 HP·점유 슬롯이 유지되고 재시작 시 필드·덱·광물·도구·공세 예약·슬롯 성장이 초기화됨.
- 정한 데스크톱 환경에서 60 FPS 목표의 프레임 비용을 기록하고 [UI·UX 계획](interface-plan.md)에 따라 모바일 작은 화면·터치·취소·화면 전환을 확인함. 모바일 실제 기기 성능은 별도 기록함.

## 추천 묶음 검토와 남은 검증

금 수입·슬롯 강화 가격·최종 상한·모집 종류별 콘텐츠·성공 뒤 재모집, 치료 재료·회복량·정비 재배치의 유효 칸·퇴각과 실제 저지 수, 타워 강화·교환의 비용·상한, 광물 수입·레시피 비용·수리, 안전 시작 구역의 크기·재료 접근 조건, 첫 전투 전 준비·공세 시작, 실제 기준 환경을 결정합니다. 이 항목들의 추천 기본값은 [플레이 사양](first-playable-spec.md)에 준비했습니다. 문서 계산을 통과한 초안이며 사용자가 채택한 범위만 실제 구현 테스트의 정답으로 고정합니다.
