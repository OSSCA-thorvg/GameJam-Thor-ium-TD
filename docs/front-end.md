# 메인 화면과 설정 흐름

2026-11-04 초기 화면·메인·설정 페이지 요청을 반영했습니다. 모든 화면은 기존 SDL·ThorVG 기반 C++ UI로 그리며, 데스크톱과 터치에서 같은 버튼·포커스·탐색 모델을 사용합니다.

## 화면 구성

| 화면 | 사용할 수 있는 기능 |
| --- | --- |
| 메인 | 지상·지하 디오라마, 새 원정 시작, 진행 중 원정 계속하기, 설정, 플레이 방법, 크레딧, 오른쪽 위 지구본 언어 버튼 |
| 오디오 설정 | 효과음 켜기/끄기, 볼륨 5% 단위 조절, 음악 크기 10% 단위 조절, 효과음 미리 듣기 |
| 화면·피드백 설정 | 움직임 줄이기, 피해 숫자 표시, 현재 설정을 반영한 미리보기 |
| 원정 설정 | 새 원정의 채굴 방식(암벽 발굴·갱도 탐사) |
| 언어 설정 | 한국어·English 선택, 바꾸면 바로 저장([다국어 문자열](i18n.md)) |
| 플레이 방법 | 지상 방어·지하 탐사·제작과 성장의 3단계 안내, 이전/다음 이동 |
| 크레딧 | GameJam 프로젝트와 ThorVG·SDL3·Noto Sans KR·dr_mp3 안내 |
| 일시정지 | 계속하기, 설정, 플레이 방법, 메인, 새 원정, 간단한 오디오 조절, 지구본 언어 버튼 |

메인의 새 원정 시작은 출격 준비 화면을 엽니다. 첫 웨이브는 준비 화면에서 직접 시작합니다. 진행 중 판이 있으면 메인에 계속하기와 새 원정 버튼을 함께 표시하며, 새 원정은 기존 판을 버릴지 확인합니다. 취소하면 기존 타워·병력·채굴·카드를 유지합니다.

계속하기는 실행 중에는 메모리의 원정을 그대로 잇고, 새로고침·창 재시작 뒤에는 [저장된 원정](expedition-save.md)을 마지막 정비 단계부터 잇습니다. 오디오·화면 설정은 새 원정에서도 유지됩니다.

## 탐색과 게임 시간

화면의 탐색 상태와 한 판의 전투/정비 단계를 분리했습니다. 메인·설정·플레이 방법·크레딧을 보고 있을 때는 고정 게임 갱신을 실행하지 않으므로, 웨이브와 진행 중 광부 작업이 멈춥니다. 메뉴 장식과 UI 사운드는 계속 사용할 수 있습니다.

- 게임 HUD의 설정 버튼은 현재 원정을 보존하며 설정을 엽니다.
- 뒤로는 실제로 해당 페이지를 열었던 화면으로 돌아갑니다. 설정 → 플레이 방법 → 뒤로는 설정으로 돌아갑니다.
- 설정에 들어오기 전 수동 일시정지 상태였다면 돌아와도 일시정지를 유지합니다. 진행 중 설정만 잠깐 열었다면 뒤로 돌아간 뒤 진행을 재개합니다.
- 일시정지에서 메인으로 이동한 뒤 계속하기를 누르면 같은 원정을 재개합니다.
- 종료된 판에서 메인으로 나가면 유효하지 않은 계속하기 버튼을 남기지 않습니다.
- `Esc`는 보조 페이지에서 뒤로, 메인에서는 그대로 머물며, 게임에서는 기존 선택 취소·일시정지로 동작합니다. 메인의 `Space`는 시작/계속하기입니다.

## 설정 적용

움직임 줄이기를 켜면 손패 전환은 즉시 완료되며, 흔들림·발사 반동·피격 눌림·장식 애니메이션·확장 파편을 간소화합니다. 전투에서 필요한 적 이동과 실제 피해 판정은 그대로 진행합니다. 피해 숫자는 별도 옵션으로 표시/숨김을 선택할 수 있습니다.

기본값 복원은 볼륨 45%·효과음 켜짐·움직임 줄이기 꺼짐·피해 숫자 표시로 돌아갑니다. 원정 자체는 초기화하지 않습니다. 기존 `S` 음소거·`V` 볼륨 순환도 유지하며, MP3 교체는 [사운드 안내](audio-system.md)를 따릅니다.

애니메이션 방식에서 벡터 원본과 공유 프레임을 비교할 수 있습니다. 현재 기본값은 실측에 따른 벡터 원본이며, 두 모드는 같은 개체 시각과 고정 위상차를 사용합니다. [공유 자원·측정 결과](shared-animation-cache.md)를 참고합니다.

## 실제 코드와 검증

- [Shell.h](../src/game/presentation/Shell.h): 게임 전용 화면 탐색·뒤로 이력·현재 원정 유무·표현 설정.
- [FrontEnd.cpp](../src/game/presentation/FrontEnd.cpp): 메인 디오라마·설정·안내·크레딧의 반응형 표현과 UI 등록.
- [AppFlow.cpp](../src/app/AppFlow.cpp): 화면 이동·원정 보존/초기화·설정·게임 갱신 허용 여부.
- [State.h](../src/game/presentation/State.h): 세션의 AppState와 판의 PlayState 수명 분리.
- [GameplayController.cpp](../src/app/GameplayController.cpp): 선택·배치·채굴 등 플레이 조작과 오래된 입력 검증.
- [Application.cpp](../src/app/Application.cpp): 객체 조합·고정 갱신·프레임 출력.
- [frontend.js](../tests/browser/frontend.js): 실제 클릭·키 입력으로 탐색·설정·일시정지 유지·원정 계속하기·새 판 확인을 검사합니다. 1200×900·980×739·390×844·320×568·1200×568에서 활성 버튼의 경계와 겹침도 확인합니다.

독립적인 탐색·카드 동작은 [rules_test.cpp](../tests/native/rules_test.cpp)에서 SDL/ThorVG 없이 확인하고, 기존 브라우저 전투·채굴·철수·카드·오디오 시나리오는 메인에서 새 원정을 여는 흐름으로 갱신했습니다.

최신 소유권·폴더 배치는 [현재 구현 아키텍처](current-architecture.md)를 확인합니다.
