# 카드 코스트 회복 표시

2026-11-08 피드백을 반영해 손패 카드의 에너지 부족을 시계 방향 진행도로 표시합니다. [카드 정보 UI](card-information.md)와 [하단 에너지·배치 미리보기](placement-preflight.md)를 이어가는 변경입니다.

## 표시 방식

- 코스트 숫자는 계속 읽을 수 있게 유지합니다. 부족한 에너지가 회복되면 숫자 둘레의 파란 원이 12시부터 시계 방향으로 차오릅니다.
- 카드 그림의 어두운 부분도 같은 비율로 시계 방향으로 걷힙니다. 숫자·이름·종류는 그림의 어두운 마스크와 분리합니다.
- 실제 에너지가 비용 이상이면 원래 사용 가능한 카드 모습으로 돌아옵니다.
- 잘못된 배치 위치·슬롯 부족·최고 레벨처럼 기다려도 해결되지 않는 조건은 정적인 빨간 테두리로 구분합니다. 에너지 상한보다 비싼 카드에도 끝날 수 없는 회복 진행도를 표시하지 않습니다.

## 진행도의 기준

[CardCharge](../src/game/presentation/CardCharge.h)는 UI가 받은 현재 규칙 판정과 실제 비용을 읽습니다. 다음 에너지 회복의 소수 진행도를 현재 보유량에 더한 뒤 필요한 비용으로 나눕니다.

~~~text
진행도 = (현재 에너지 + 다음 1 에너지의 회복 진행도) / 실제 카드 비용
~~~

예를 들어 비용 3인 카드에 에너지 1이 있고 다음 에너지 회복이 절반 진행됐으면 50%입니다. 에너지가 1씩 늘 때마다 진행도를 처음부터 다시 시작하지 않습니다. 이미 설치된 같은 건물의 강화 비용이 2라면 그 가격으로 계산하고, 빈 패드를 가리켜 설치 비용이 3으로 바뀌면 미리보기도 해당 가격으로 바뀝니다.

별도 카드 타이머·쿨다운 상태·보상 이벤트를 만들지 않습니다. `RunState.energy`와 `energyTime`, 카탈로그의 회복 간격을 읽기만 하므로 일시정지·배속과 동일하게 동작합니다. 동작 줄이기는 장식 연출만 줄이며 실제 자원 진행 정보는 계속 표시합니다. 정비·메인 화면에서는 손패 진행 표시를 보유하지 않습니다.

일반 카드 대기와 표적별 판정은 기존 `playAvailability`/`previewPlay`를 그대로 사용합니다. 드래그·손패 선택·호버·길게 누르기 조작은 변경하지 않았습니다. 손패 교체 연출에서 빠져나가는 옛 카드는 기존 모습을 유지하고 새 카드부터 현재 에너지 상태를 표시합니다.

읽기 전용 `handCharge` 진단은 마지막으로 그린 네 카드의 ID·비용·모드·진행도를 제공합니다. 모드는 `Ready=0`, `Charging=1`, `Blocked=2`입니다. 정비 등 손패가 없는 화면은 빈 배열입니다.

## 2026-11-09 디자인 통합

리본형 웨이브 표시, 하트·방패 HUD, 카드 명패·종류 배지, 덱 트레이와 접이식 작전 안내창 디자인을 유지했습니다. 코스트 둘레의 회복 원과 카드 그림의 회복 마스크는 이 카드 디자인 위에 적용합니다.

안내 탭·X·확인 버튼은 서로 다른 ID를 사용하며 기존 메뉴 버튼 ID는 유지합니다. 안내창 본문이 뒤의 전장 입력을 막고, 모바일에서는 가려진 조작 버튼도 비활성화합니다. 안내 닫기는 전투를 시작하지 않습니다. 웨이브 시작이나 카드 선택으로 직접 조작을 시작하면 안내를 닫고, 카드를 드래그하는 중에는 안내창이 사거리 미리보기를 가리지 않습니다.

320px 화면에서는 선택 카드·배치된 아군의 설명을 줄여 조작 버튼을 분리합니다. 안내창 높이는 덱 위의 공간에 맞추고, 상태 메시지는 안내창보다 먼저 그립니다. 긴 안내 문구에는 패널 폭 제한을 적용합니다.
