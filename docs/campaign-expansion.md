# 캠페인 확장 구현

2026-11-11. 정규 원정은 세 구역의 8·10·12웨이브로 구성한다. 2026-11-12에 다섯 구역의 8·10·12·14·16웨이브로 늘렸다. 기존 3웨이브 기본 콘텐츠는 규칙 테스트의 작은 시나리오로 남기고, 별도 연습 원정은 기존 7단계를 유지한다. 이전 문서의 ‘첫 3웨이브 검증’은 초기 프로토타입 범위다.

2026-11-12 적 역할을 9종으로 늘리고 공세를 역할별 패턴·구역 보스로 다시 구성했다. 역할 수치, 웨이브 구성과 적 수, 예고·화면 표시는 [적 로스터와 공세 구성](enemy-roster.md)이 최신이다. 아래의 진입로 개방·집중 공세·예고 규칙은 그대로 유지한다.

난이도 곡선 측정, 구역별 체력·속도 배율과 공세 수치 조정은 [밸런스 패스](balance-pass.md)를 따른다.

2026-11-13 1구역을 24×14에서 30×18로 넓히고 남서쪽에서 거점 동쪽으로 들어오는 세 번째 입구 `남서 광산길`(4웨이브)과 패드 7개를 더했다. 2구역은 32×18에서 34×20으로 넓히고 남쪽 지름길의 시작을 새 남동쪽 공간으로 옮겼으며(길이 +6) 패드 4개를 더했다. 기존 경로·패드·바위 좌표는 그대로다. 3~5구역은 그대로다.

2026-11-13 정비에 T3 드릴·건물 각성(Lv4·5)·광부 고용·보급 상자를 더했다. 가격·한도·화면과 봇 측정은 [정비 자원 사용처](economy-sinks.md)에 있다.

2026-11-13 구역마다 전장 기믹 하나를 더했다. 1구역 낙석 바위, 2구역 특성 패드, 3구역 갱도 터널, 4구역 용암 분출구, 5구역은 셋의 복합이다. 규칙·수치·화면과 봇 측정은 [구역별 전장 기믹](stage-gimmicks.md)에 있다. 아래 표의 전장 크기·진입로는 그대로다.

진입로는 서로 교차하거나 거점 앞에서 합류한다. 토르륨 핵은 거점이 전장 중앙에 있고 네 방향에서 길이 모인다. 2구역부터 출발 덱에 새 카드가 섞이고, 2웨이브 확장 보상도 구역마다 다르다.

지형마다 바닥색과 장식이 다르다. 초원은 나무·바위, 흑요석은 검은 결정·균열, 동토는 침엽수·얼음, 용암은 빛나는 균열·용암 웅덩이, 토르륨 핵은 녹색 결정·유적을 그린다. 장식은 길·패드·배치 칸과 겹치지 않는다. 길은 테두리와 진행 방향 화살표로 표시하고, 입구 가까운 화살표는 공세가 있을 때 붉게 움직인다.

진입로는 각자의 출현 시각·진행 거리·경로를 갖고 같은 거점에 합류한다. 후반에는 여러 입구가 동시에 공격하고, 일부 중간 웨이브는 한 입구에 집중한다. 표층 첫 두 웨이브는 기존 입문 구성을 유지한다. 타워는 경로가 다른 적끼리도 거점까지 **남은 거리**를 비교한다. 아군은 자신이 저지하는 적을 우선 공격한다.

입구 표식과 HUD에 현재 또는 다음 웨이브의 경로별 예정 수를 표시한다. 아직 열리지 않은 입구에는 첫 공세 웨이브를 표시한다. 둥지에서 예약된 추가 적은 A 입구 예고에 합산한다. 2웨이브 뒤에는 기존의 긴 우회로/짧은 경로 확장 선택을 한 번 제공하며, 기존 배치와 생존 병력은 보존한다.

## 카메라와 조작

- 마우스 휠 또는 `+` / `-`: 확대·축소. 휠은 커서 위치를 기준으로 확대한다.
- 빈 전장 드래그: 지도 이동. 카드 배치와 유닛 이동이 선택되어 있을 때는 해당 조작을 우선한다.
- HUD의 `−` / `1x` / `+`: 터치에서도 확대·전체 보기·축소를 조작한다. `0`도 전체 보기로 돌아간다.
- 확대는 전체 보기의 1~4배이며, 카메라가 전장 밖으로 이동하지 않도록 제한한다.
- 2구역부터 전투 화면은 타일이 데스크톱 30px·좁은 화면 26px 이상이 되도록 확대하고 거점을 중심에 둔 채 시작한다. 1구역은 넓은 화면에서 전체 보기로, 좁은 화면에서는 첫 입구와 거점이 함께 보이는 만큼만(최대 20px) 확대해 두 지점 가운데로 시작한다. 연습 원정은 전체 보기로 시작한다.
- 화면 밖 입구는 전장 가장자리의 화살표·예정 수로 표시하며, 누르면 그 입구로 이동한다.
- 전장 일부만 보일 때 왼쪽 아래 미니맵에 길·거점·건물·적과 현재 화면 범위를 표시한다. 미니맵을 누르면 그 위치로 이동한다. 카드 배치와 유닛 이동 중에는 표시하지 않는다.
- 카드 드래그 중에는 휠로 위치를 바꾸지 않는다. 배치·사거리 미리보기·클릭 판정은 같은 화면 변환을 사용한다.
- 정지·설정·모달·연습 원정에서는 카메라 조작을 막는다. 두 손가락 확대는 현재 지원 범위에 포함하지 않는다.

## 추가 채굴층

B2는 3웨이브 뒤, B3는 7웨이브 뒤(1구역 5웨이브, 2구역 6웨이브 뒤) 열리며 T2 곡괭이가 필요하다. 구역별 지도·특수 타일·유물은 [구역별 채굴층과 특수 타일](mine-content.md)에 정리했다. 정비 화면의 채굴 영역 오른쪽 위에서 내려갈 수 있다. 광부의 작업을 마치고 확장·보상 선택을 끝내야 한다.

내려가면 새로운 안전 시작 갱도와 광맥·둥지·숫자 정보가 활성화된다. 보유 자원·장비·배치·체력·현재 정비의 남은 굴착·스캔은 유지한다. 층 이동 자체로 보상이나 추가 행동을 지급하지 않는다. **이전 층으로 돌아갈 수 없으며**, 확인창에서 남겨지는 미굴착 칸 수를 보여준다. 내려가지 않고 남은 층을 계속 캐는 선택도 가능하다. 각 정비는 기존대로 5굴착·무료 스캔 1회이며 조기 종료할 수 있다.

작은 모바일 채굴 화면은 자원 중심 HUD와 압축된 정비 패널을 사용해 채굴판 높이를 확보한다. 안내·획득 메시지는 타일을 덮지 않고 정비 패널 안에 표시한다.

### 채굴판 크기와 표시

정규 원정의 채굴층은 7열×11행이다. 층 정의(`MineLayerDefinition`)가 너비·높이·시작 칸·칸 목록을 가지며, `MineCatalog.cpp`가 문자 지도로 다섯 구역의 B1·B2·B3를 각각 작성한다(2026-11-12 이전에는 세 지도를 짝수 구역에서 좌우 반전해 같이 썼다). 얕은 곳에 철·구리 광맥, 중간에 통로를 남긴 단단한 암반 띠, 깊은 곳에 금·수정과 둥지를 둔다. 규칙 시험과 연습 원정은 기존 5×6 판을 유지한다.

- 보드가 화면보다 길면 휠·끌기로 세로 스크롤하고, 광부가 작업하는 동안 화면이 광부를 따라간다. 층을 내려가면 스크롤이 맨 위로 돌아간다.
- 지층 색은 깊이와 층에 따라 어두워진다. 굴착한 칸은 이웃 갱도와 이어진 굴, 받침목·사다리·등불로 그린다. 열린 갱도에서 먼 암석일수록 어둡다.
- 단단한 암석은 띠무늬와 곡괭이 등급 배지로, 공개된 광물은 광석 조각과 수량으로, 공개된 둥지는 붉은 눈과 테두리로 표시한다.
- 둥지 수 숫자는 값이 1 이상이고 알려진 칸에만 가운데에 색으로 구분해 표시한다(1 파랑, 2 초록, 3 빨강). 채굴 화면 머리에 숫자의 뜻을 적는다.
- 굴착이 끝나면 광물 색의 획득 수량이 떠오르고 파편이 튄다. 둥지를 파면 붉은 파동과 ‘다음 웨이브 +N’을 표시한다. 동작 줄이기 설정에서는 이동·파편·파동 없이 글자만 표시한다.
- 정비 패널은 도구·장비 / 부대 / 모집으로 나눈 줄마다 아이콘, 효과, 광물 칩 가격, 부족한 광물, 보유 상태를 표시한다. 좁은 화면에서는 같은 항목을 작은 타일 격자로 보여 준다.

## 원정과 구역 선택의 소유권

메인의 구역 탐색은 선택 번호만 바꾼다. 진행 중 원정의 배치·HP·콘텐츠를 교체하지 않는다. ‘계속하기’는 실제 진행하던 구역으로 복귀하며, ‘새 원정’ 확인 후에만 선택한 구역의 새 상태를 만든다. 패배·재시도도 해당 구역의 실제 웨이브 수를 사용한다.

최종 웨이브 승리 즉시 다음 구역을 해금하고 저장한다. ‘다음 구역’ 버튼을 누르지 않고 메인으로 나가도 해금이 유지된다. 다음 구역은 새로운 자원·덱·전장으로 시작한다. 진행 중 원정은 2026-11-14부터 웨이브 사이마다 저장되어 새로고침 뒤에도 이어진다([원정 저장](expedition-save.md)).

## 구현 경계와 검증

`StageCatalog.cpp`가 구역별 크기·경로·공세·채굴층을 제공한다. `Run`이 경로 이동·표적 선택·예고·굴착층 전환을 검증한다. `AppFlow`가 선택/활성 원정/해금을 구분하고, 범용 `engine/view/Camera2D`와 앱의 `MapCamera`가 투영과 조작을 나눈다. SDL은 정규화한 휠·마우스·터치·키보드 입력을 전달한다.

새 네이티브 테스트는 잘못된 경로 참조와 경계, 예고/실제 스폰 일치, 최종 웨이브 종료, 지층 비용·조건·자원 보존, 구역 탐색과 재개, 카메라 변환과 모달 입력을 검증한다. 별도 자동 플레이는 실제 카드·에너지·채굴·제작 명령만 사용하여 다섯 구역을 모두 완주한다. 고정 0.1초 시뮬레이션에서 전투 누적 시간은 약 257/512/585/954/965초였다. 이 결과는 콘텐츠의 진행 가능성을 확인하며, 사람의 체감 난이도나 60 FPS 달성을 증명하지 않는다.

브라우저 캠페인 테스트는 실제 SDL 입력으로 구역 선택, 확대·지도 이동·전체 보기, 확대 상태의 카드 사거리와 배치, 진행 원정 보존, 320px 터치 조작을 확인한다. 기존 튜토리얼·카드·전투·오디오·저장 설정 테스트도 함께 실행한다.

```sh
python3 tools/build.py native
meson test -C build/native --print-errorlogs
python3 -m unittest discover -s tests -p 'test_*.py' -q
python3 tools/build.py web
npm run test:browser
```
