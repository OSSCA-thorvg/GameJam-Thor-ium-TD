# Thor-ium TD 문서 안내

프로젝트 첫 화면은 [README](../README.md)입니다. 이 문서는 기획·설계·구현 기록 전체의 목차와 날짜별 변경 기록입니다.

## 변경 기록

2026-11-14 적 3종(날아다니는 동굴박쥐, 가까이 와야 보이는 그림자, 저지를 한 번 뛰어넘는 도약꾼)과 새 테마의 [6·7구역](new-roles-and-stages.md)을 더해 **7개 구역**이 되었습니다. 6구역 공명 수정굴은 레버로 보내는 광차와 수정 군집, 7구역 부식의 늪은 적을 늦추는 늪과 눌러서 터뜨리는 가스통이 있습니다.

2026-11-13 채굴에 두 번째 방식인 [암벽 발굴](excavation.md)을 더했고 설정의 원정 탭에서 기존 갱도 탐사와 바꿀 수 있습니다. 구역마다 [전장 기믹](stage-gimmicks.md)(낙석 바위·특성 패드·갱도 터널·용암 분출구)이 하나씩 있고, 1구역은 30×18·입구 3개, 2구역은 34×20으로 [넓혔습니다](campaign-expansion.md). 채굴 화면의 광석·도구 그림은 직접 만든 SVG이고, 5구역 후반의 [프레임 예산](frame-budget.md)을 쟀습니다.

2026-11-12 정규 캠페인을 **5개 구역·8/10/12/14/16웨이브**로 확장했습니다. 화염방사탑·저격탑·증폭 발전기·타르 웅덩이 카드를 추가했습니다. 큰 전장과 다중 진입로, 맵 확대·이동, 추가 채굴층, 구역 해금·선택·재개를 제공합니다. 조작과 실제 범위는 [캠페인 확장 구현](campaign-expansion.md)을 확인합니다.

2026-11-04 SDL3·ThorVG·공통 C++ UI의 첫 시연판을 구현했습니다. macOS 네이티브와 웹에서 카드 배치·3웨이브 전투·채굴·제작·모집을 연결했습니다. 첫 피드백으로 배치한 건물·유닛의 선택·철수와 채굴 기지 테마의 HUD·손패·정비창을 추가했습니다. 후속 피드백으로 손패 순환·등장 애니메이션과 발사·피격·처치 연출을 연결했습니다. 사운드는 23종 합성 효과음과 음소거·볼륨, MP3 파일 교체를 지원합니다. 메인·설정·플레이 방법·크레딧에서 새 원정과 현재 원정 계속하기를 사용할 수 있습니다. 실제 범위와 검증은 [구현 기록](implementation-v0.1.md)을 확인합니다. 기획 전체나 밸런스·성능 목표의 완료와는 구분합니다.

개발 전 시작 계획 → 규칙 선택지 → 아키텍처 → 결정 기록 순서로 읽습니다. 전체 아이디어는 통합 기획안, 자원 역할은 경제안에서 확인합니다.

- 전투·카드: 기본 덱 8·손패 4, 건물 설치·동종 강화·타종 교체·에너지 손패 교환, 같은 카드 반복 유닛 소환·기본 6슬롯·생존 HP 유지입니다.
- 채굴: 구역마다 지형 팔레트가 다른 7×11 수작업 채굴층 3개(규칙 시험·연습은 5×6)와 보물 상자(원정 유물)·카드 화석·에너지 수정·붕괴 암반 특수 타일, 정비당 5굴착·무료 스캔 1회, 열린 갱도 4방향 이동·최초 둥지 8이웃 숫자입니다. 스캔은 경계 1칸의 광물·둥지·숫자만 공개하고 현재 작업 완료 뒤 조기 정비 종료가 가능합니다. 숫자 0은 정보만 연쇄 공개하고 실제 둥지 굴착만 다음 웨이브 추가 적을 예약·예고합니다.
- 경제·획득: 철·구리·수정은 도구·공통 장비, 금은 슬롯 강화·유닛 카드 3택1 모집에 씁니다. 보유한 종류도 후보에 포함하며 제시 3종은 서로 다릅니다. 모집 후보 확인은 무료, 덱 교체 확정 시 결제, 취소는 무소모·동일 후보 유지입니다. 획득 시 1대1 교체로 활성 8장을 유지하고 정비 손패에는 최근 획득 1장을 우선 포함합니다.
- 공간·확장: 첫 검증은 고정 경로·배치 칸, 2웨이브 뒤 지상 확장 1회입니다. 후속 자유 배치·경로 재계산·지하 중력·사다리로 전환할 경계를 준비합니다.
- 환경·후속: 데스크톱 60 FPS 우선·모바일 UI·UX 준비입니다. 도감 선택 UI·룬 공격 방식 분기는 후속이며 실제 기기·안전 구역 크기·가격·후보 종류별 콘텐츠·재모집·치료량과 보드 경제 검증은 남았습니다.

v0.1 가격을 현재 제작·유닛 규칙에 그대로 적용하지 않습니다. 선택한 규칙과 실제 게임·성능 검증 완료를 구분합니다. [첫 보드·경제 초안](first-board-economy.md)의 네 경로는 문서 계산으로 확인했고 실제 전투 균형은 미검증입니다.

## 문서 검증

프로젝트 폴더에서 `python3 -m unittest discover -s tests -p 'test_*.py' -v`로 링크·문서 연결·결정 참조·덱 구성의 일관성을 검사합니다. Python 표준 라이브러리만 사용하며 게임 로직·밸런스·렌더링 성능의 검증과 구분합니다.

현재 구조의 콘텐츠·애니메이션·전투 개선과 실제 앱 출력 구간 측정은 [아키텍처 검토 후속](architecture-follow-up.md)에 정리했습니다.
