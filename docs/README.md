# Thor-ium TD 문서 안내

프로젝트 첫 화면은 [README](../README.md)입니다. 이 문서는 기획·설계·구현 기록 전체의 목차와 날짜별 변경 기록입니다.

## 변경 기록

2026-11-14 화면 문장을 언어별 JSON 표에서 읽는 [다국어 구조](i18n.md)를 넣었습니다. 전투·채굴·튜토리얼·카드 정보와 규칙 메시지까지 모든 화면 문장이 한국어·영어를 지원합니다. 언어는 메인과 일시정지 창 오른쪽 위의 지구본 버튼이나 설정의 언어 탭에서 바꿉니다. 개발 전 기획·조사 문서는 [보관 문서](archive/README.md)로 옮겼습니다.

2026-11-14 적 3종(날아다니는 동굴박쥐, 가까이 와야 보이는 그림자, 저지를 한 번 뛰어넘는 도약꾼)과 새 테마의 [6·7구역](new-roles-and-stages.md)을 더해 **7개 구역**이 되었습니다. 6구역 공명 수정굴은 레버로 보내는 광차와 수정 군집, 7구역 부식의 늪은 적을 늦추는 늪과 눌러서 터뜨리는 가스통이 있습니다.

2026-11-13 채굴에 두 번째 방식인 [암벽 발굴](excavation.md)을 더했고 설정의 원정 탭에서 기존 갱도 탐사와 바꿀 수 있습니다. 구역마다 [전장 기믹](stage-gimmicks.md)(낙석 바위·특성 패드·갱도 터널·용암 분출구)이 하나씩 있고, 1구역은 30×18·입구 3개, 2구역은 34×20으로 [넓혔습니다](campaign-expansion.md). 채굴 화면의 광석·도구 그림은 직접 만든 SVG이고, 5구역 후반의 [프레임 예산](frame-budget.md)을 쟀습니다.

2026-11-12 정규 캠페인을 **5개 구역·8/10/12/14/16웨이브**로 확장했습니다. 화염방사탑·저격탑·증폭 발전기·타르 웅덩이 카드를 추가했습니다. 큰 전장과 다중 진입로, 맵 확대·이동, 추가 채굴층, 구역 해금·선택·재개를 제공합니다. 조작과 실제 범위는 [캠페인 확장 구현](campaign-expansion.md)을 확인합니다.

2026-11-04 SDL3·ThorVG·공통 C++ UI의 첫 시연판을 구현했습니다. macOS 네이티브와 웹에서 카드 배치·3웨이브 전투·채굴·제작·모집을 연결했습니다. 첫 피드백으로 배치한 건물·유닛의 선택·철수와 채굴 기지 테마의 HUD·손패·정비창을 추가했습니다. 후속 피드백으로 손패 순환·등장 애니메이션과 발사·피격·처치 연출을 연결했습니다. 사운드는 23종 합성 효과음과 음소거·볼륨, MP3 파일 교체를 지원합니다. 메인·설정·플레이 방법·크레딧에서 새 원정과 현재 원정 계속하기를 사용할 수 있습니다. 실제 범위와 검증은 [구현 기록](archive/implementation-v0.1.md)을 확인합니다. 기획 전체나 밸런스·성능 목표의 완료와는 구분합니다.

## 지금의 게임

- 캠페인 7개 구역. 구역마다 8웨이브 이상, 입구 여러 개, 전장 기믹 하나와 보스가 있습니다.
- 지상: 손패 4장으로 건물·유닛·마법 카드를 씁니다. 건물은 내구도가 있어 수리하고, 같은 카드를 겹쳐 강화합니다. 적은 16종입니다.
- 지하: 웨이브 사이 정비 시간에 채굴합니다. 기본은 암벽 발굴이고 설정에서 갱도 탐사로 바꿀 수 있습니다. 캔 광물로 도구·장비를 만들고, 금과 전투 조각으로 유닛·건물을 모집합니다.
- 연습 원정(튜토리얼), 원정 저장, 배경음악, 한국어·영어를 지원합니다.
