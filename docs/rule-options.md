## Q-19 — 유닛의 이동·수명·재사용을 어떻게 묶을까요?

| --- | --- | --- |

| C | 주변 적 자동 추적과 복귀, 재배치 대기시간 | 역동적인 교전, 경로·추적·복귀·타이머 규칙 증가 |

- 검증: 같은 카드의 여러 유효 사용이 각각 새 개체를 생성함, 전체 슬롯 포화 시 무소모 거절, 사망·제거에 따른 슬롯 반환, 동일 명령 재처리의 이중 반영 방지.
- 선택: B
- 상태: 일부 확정
- 확정 범위: 같은 카드 반복 소환, 첫 유닛당 1슬롯·기본 6슬롯, 플레이 중 슬롯 상한 업그레이드, 생존 유닛과 남은 체력 유지, 지정 위치 자동 교전·저지입니다.
- 남은 결정: 금 소비량·강화 단계·최종 상한, 치료 재료·회복량, 재배치의 유효 칸·자리 교환·퇴각, 실제 저지 수입니다.

### Q-19의 추가 확정과 남은 세부

사용자는 재화 광물을 만들어 슬롯 강화·유닛 뽑기에 쓰는 방향, 정비 재료 선택 치료, 정비 무료 재배치를 선택했습니다. 같은 질문을 다시 미정으로 취급하지 않습니다.

슬롯 강화의 6→8→10은 단계 예시이며 최종 수치가 아닙니다. 치료 재료를 금으로 통일할지와 회복량·횟수도 미정입니다. 재배치는 같은 개체의 위치만 바꾸고 현재 HP·점유 슬롯을 보존합니다. 모집 결과는 Q-23=A로 확정했으며 가격·후보 풀·덱 반영은 Q-14·Q-20에서 이어 정합니다. 자원 역할은 [경제안](economy-plan.md)을 참고합니다.

## Q-20 — 보상 교체와 다음 손패는 어떻게 처리할까요?

| 안 | 구성 | 영향 |
| --- | --- | --- |
| A | 정비 후 손패 재구성, 최근 획득 카드 1장을 우선 포함 | 3웨이브에서도 새 카드를 시험, 정비마다 순환 흐름 초기화 |
| B | 손패·대기열 유지, 선택한 카드 인스턴스 위치에 새 카드 삽입 | 순환 전략 유지, 새 카드가 늦게 도착할 수 있어 미리보기 필요 |
| C | 보관함에 획득하고 별도 덱 편집 | 획득·사용 분리, 보관함·편집 상태 증가 |

- 추천: A. 해당 구간의 확장·보상을 먼저 처리한 뒤 정비에서 채굴·제작·금 모집·덱 편집·치료·재배치를 오가고 준비 완료 때 손패를 처리하는 흐름을 제안합니다. 금을 새로 얻은 뒤에도 모집과 덱 반영이 가능해야 합니다. 코일은 제작 시 활성 덱의 전격탑 조건을 검사합니다. 카드 교체만으로 기존 설치물·생존 유닛을 제거하거나 회복하지 않는 안이며 해당 종류의 카드가 덱에 남아 있지 않아 기존 설치물의 동일 카드 강화 기회가 사라지는 경우는 안내합니다.
- 검증: 교체 후 활성 8장·손패 4장, 최근 획득 우선, 손패·대기열에 같은 인스턴스 중복 없음, 여러 획득과 교체 취소·단계 전환 재처리.
- 선택: A
- 상태: 일부 확정
- 확정 범위: 획득 카드는 기존 1장과 교체하고 활성 덱 8장을 유지합니다. 정비 후 손패를 재구성하며 활성 덱의 최근 획득 카드 1장을 우선 포함합니다.

- 검증: 모서리·가장자리 8이웃 수, 실제 굴착 4방향 연결, 정보 공개와 작업 예산 분리.

- 상태: 확정
- 확정 범위: 숫자는 최초 둥지 배치의 주변 8칸 수로 고정하고 둥지를 열거나 제거해도 바뀌지 않습니다. 열린 둥지 위치는 식별할 표식으로 남기는 표현안을 권장합니다.
- 남은 결정: 안전 구역 크기는 Q-09에서 검토합니다. 실제 굴착 뒤 숫자 0은 연결 영역과 경계 숫자를 정보로만 연쇄 공개합니다. 스캔은 선택한 경계 1칸의 광물·둥지·숫자를 공개하기로 정했습니다. 숫자 공개만으로 광물·굴착 작업을 자동 지급하는 규칙은 선택하지 않았습니다.

## Q-09 — 확실한 안전 칸이 없을 때 어떻게 할까요?

| 안 | 구성 | 영향 |

- 추천: A. 둥지 실제 굴착의 일회성 추가 공세도 후속 답변으로 확정했습니다. 숫자로 무조건 완전 해결된다고 약속하는 대신 보드별 선택을 검증합니다.
- 검증: 강제 추측·다음 도구 접근의 관계, 스캔 공개와 실제 굴착 분리, 추가 공세 중복 방지.

- 상태: 일부 확정
- 확정 범위: 안전한 시작 구역, 정비당 무료 스캔 1회, 남은 굴착을 포기하고 정비를 끝내는 선택입니다.
- 후속 확정: 광부가 접근 가능한 갱도 경계의 미굴착 타일 1칸에서 광물·둥지 유무·숫자를 확인합니다. 스캔은 굴착 횟수를 쓰거나 광물을 얻지 않으며 실제 굴착과 별개입니다. Q-03 후속으로 현재 이동·굴착 완료 뒤 정비 종료도 정했습니다.
- 추가 확정: 실제 굴착한 숫자 0에서 연결된 0 영역과 경계의 숫자만 자동 공개하고, 실제 둥지 굴착은 즉시 광부 피해 없이 다음 웨이브 추가 적을 한 번 예약·예고합니다. 스캔은 선택 1칸 공개입니다.
- 남은 결정: 안전 구역 크기·초기 공개·추가 적 수입니다. 추측 없이 진행할 수 있는 범위는 실제 보드로 검증합니다.

| 항목 | 답변 기록 | 상태 |
| --- | --- | --- |
| 시작 | 안전한 시작 구역 | 확정, 크기·초기 공개 미정 |
| 스캔 | 정비당 무료 1회·접근 가능한 경계 1칸의 광물·둥지·숫자 공개·굴착 횟수와 자원 불변 | 확정 |
| 종료 | 현재 이동·굴착 완료 뒤 남은 굴착을 포기하고 정비 조기 종료 | 확정 |

### Q-09 후속 비교안

| 항목 | 추천안 | 대안 | 선택 |
