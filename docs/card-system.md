# 카드 분류·획득·출발 편성 제안

작성일: 2026-10-31. 사용자 방향과 구체 규칙 제안을 구분합니다. 카드 분류와 플레이 중 획득을 반영하며, 출발 편성의 장수·점수와 영구 도감의 세부 규칙은 검토안입니다. 확정 상태는 [결정 문서](decisions.md)를 따릅니다.

2026-11-03 개발 전 조사에서 Q-18·Q-19·Q-20의 시작 손패·유닛 재사용·획득 교체 규칙을 보완했습니다. [규칙 선택지](rule-options.md)에 대안과 추천을 정리했으며 이후 사용자 답변으로 첫 검증 기본 덱 8장·손패 4장·도감 선택 UI 후속, 획득 시 1대1 교체, 정비 후 최근 획득 우선 손패 재구성을 확정했습니다.

이후 Q-19=B와 후속 답변으로 같은 카드 반복 소환·기본 6슬롯·첫 유닛당 1슬롯·금 재화 슬롯 강화·생존 HP 유지·지정 위치 저지·정비 재료 선택 치료·무료 재배치를 선택했습니다. 카드 장수는 동시 유닛 상한이 아닙니다. 가격·치료량·유효 재배치 칸·퇴각은 미정입니다.

## 반영할 방향

- 카드의 행동 분류는 마법·건물·유닛입니다.
- 플레이 보상과 맵 확장을 통해 한 판 안에서 카드를 얻으며 덱을 발전시킵니다.
- 다음 판에는 현재 전투 덱과 강화·룬을 그대로 이어가지 않고 새 출발을 합니다.
- 추가 아이디어는 발견한 카드의 기록을 남기고 출발 덱 일부에 사용할 수 있게 하는 것입니다. 이는 이전 판의 성장 결과 전체를 계승하는 것과 구분합니다.

## 세 가지 행동 분류

| 분류 | 역할 | 지속 방식 제안 | 예시 |
| --- | --- | --- | --- |
| 마법 | 즉시 피해·감속·강화 등 위기 대응 | 사용 후 효과 종료, 일반 카드는 다시 순환 | 폭발·서리·과충전 |
| 건물 | 위치를 정해 지속 방어 | 설치한 상태를 다음 웨이브에도 유지 | 연사 포탑·전격탑·포격탑 |
| 유닛 | 체력을 가진 아군을 반복 소환, 기본 6슬롯에서 상한 성장 | 생존 개체와 남은 HP·점유 슬롯을 다음 웨이브에 유지 | 경비병·사수·폭파 드론 |

건물은 설치 지점, 유닛은 아군 배치 구역, 마법은 카드별 유효 대상을 사용하는 제안입니다. 유닛은 지정 위치에서 자동 교전·저지하고 같은 카드가 소환한 유닛이 살아 있어도 빈 슬롯과 다른 조건이 충족되면 다시 소환할 수 있습니다. 정비 무료 재배치는 같은 개체·HP·점유 슬롯을 유지하며 정확한 배치 구역·사거리·저지 수·표적 우선순위·자리 교환은 추가 검토합니다.

카드의 분류, 희귀도, 출발 편성점수, 전투 코스트는 서로 다른 값입니다. 핵무기 테마의 공격은 마법 분류 후보이며, 일회용 충전이나 별도 슬롯 여부는 사용 정책으로 다룹니다. 채굴 장비는 도구 슬롯에 장착하는 아이템으로 검토하고 카드의 네 번째 행동 분류로 자동 추가하지 않습니다.

## 두 시간 범위의 성장

| 범위 | 남길 것 | 새 판의 처리 |
| --- | --- | --- |
| 발견 기록·도감 | 발견한 카드의 정의 ID와 출발 사용 가능 여부 | 일부 출발 편성에 활용하는 검토안 |
| 출발 편성 | 선택한 카드 종류와 장수 | 편성 규칙을 다시 검사해 새 카드 인스턴스를 생성 |
| 이번 판의 전투 상태 | 획득 카드, 타워·유닛, 레벨, 룬, 재료, 지원 충전 | 종료 후 다음 판에 자동 계승하지 않는 방향 |

카드 발견을 승패와 무관하게 도감에 기록할지와 저장 시점은 추가 결정이 필요합니다. 도구 등급의 계승 여부는 카드 도감과 별도 질문으로 유지합니다.

## 출발 덱: 첫 검증 확정과 후속 편성안

첫 검증은 기본 덱 8장·손패 4장으로 시작하며 도감 선택 UI는 후속입니다. 정확한 카드 구성·코스트·첫 손패 역할 보장은 별도 수치·콘텐츠 검토입니다.

후속 도감 편성은 기본 4장과 도감 선택 4장으로 구성하는 안입니다. 기본 카드가 건물·유닛·마법을 포함하게 하여 필수 대응 수단을 보장합니다. 첫 플레이에서도 선택 칸을 채울 기본 카드 후보를 제공합니다.

전체 8장의 편성점수 합을 10 이하로 제한합니다. 점수는 전투 중 카드 사용 코스트와 별개이며, 초기에는 일반 1·희귀 2·영웅 3으로 환산하는 안입니다. 필요하면 개별 카드의 출발 편성점수를 조정할 수 있게 정의를 구분합니다.

| 출발 조합 예시 | 총 장수 | 편성점수 |
| --- | --- | --- |
| 일반 8장 | 8 | 8 |
| 일반 6장 + 희귀 2장 | 8 | 10 |
| 일반 7장 + 영웅 1장 | 8 | 10 |

합은 정확히 10이 아니라 **10 이하**로 제안합니다. 아직 상위 카드를 발견하지 못한 첫 플레이도 시작할 수 있어야 합니다. 같은 카드의 허용 장수와 일부 특수 카드의 출발 사용 조건은 별도로 정합니다.

4~8장 중 장수를 자유롭게 고르는 안도 가능합니다. 다만 적은 장수는 핵심 카드가 빨리 돌아오는 이점이 있어 등급 합만으로 같은 강도를 보장하지 않습니다. 처음에는 장수를 고정해 점수·조합의 효과를 확인하고, 가변 장수는 순환 속도까지 비교한 뒤 결정하는 쪽을 권장합니다.

## 한 판 안에서의 획득

카드 획득 시 기존 카드 한 장과 교체해 활성 덱을 8장으로 유지합니다. 별도 보관함·장수 증가는 현재 채택하지 않습니다. 금 모집은 보유 종류 포함·서로 다른 후보 3종, 후보 확인 무료·덱 교체 확정 결제·취소 무소모·동일 후보 유지입니다. 일반 획득 보상 넘김·성공 뒤 재모집·후보 만료는 미정입니다.

정비가 끝나면 현재 활성 덱으로 손패 4장을 재구성하고 최근 획득 카드 1장을 우선 포함합니다. 같은 인스턴스를 복제하지 않고 나머지 카드는 대기열로 구성합니다. 최근 카드가 다시 교체되거나 여러 장을 얻은 경우의 적용 기준은 아래 제안과 테스트로 정리합니다.

| 획득 경로 | 제안하는 보상 |
| --- | --- |
| 웨이브·주요 전투 보상 | 사용할 수 있는 카드 후보 중 선택 |
| 지상 맵 확장 | 새 구역의 특징과 연결된 카드 또는 후보 묶음 |
| 지하 유적·광맥 탐색 | 발견 카드·특수 제작법·재료 |
| 광물 제작 | 고급 카드·지원 충전·기존 카드의 분기 강화 후보 |
| 금 재화의 유닛 뽑기 | 유닛 카드 후보 3개 중 1개 획득 확정, 실제 소환은 전투 에너지 사용 |

일반 획득 보상은 선택했을 때 실제 카드 교체로 이어지게 하고, 특수 제작법은 재료를 모아 완성하는 것으로 구분하는 안입니다. 모든 새 카드에 해금과 제작 비용을 일괄 중복 적용하지 않습니다. 어떤 카드가 직접 보상이고 어떤 카드가 제작 대상인지는 콘텐츠 정의에서 정합니다.

맵 확장에서는 경로·설치 공간과 함께 카드 보상도 미리 보여줄 수 있습니다. 예를 들어 넓은 방어 지점을 여는 구역에서 포격 건물을, 아군 배치에 유리한 구역에서 유닛을 얻도록 연결하는 제안입니다. 특정 구역을 고르지 않아도 기본 덱으로 방어를 이어갈 수 있어야 합니다.

플레이 도중의 획득은 출발 편성점수 10의 제한과 분리합니다. 이 제한은 출발 조건이며 강한 카드를 얻고 덱을 발전시키는 한 판의 성장까지 막지 않는 방향입니다.

## 건물 카드 사용과 손패 교환

Q-06=A로 건물 카드는 빈 패드 설치·동종 강화·다른 종류 교체에 사용하고 전투 에너지로 손패를 교환합니다. 타워의 같은 종류 여부는 카드 인스턴스가 아닌 건물 정의로 판단하는 안입니다. 다른 카드 인스턴스라도 같은 종류의 타워를 강화할 수 있습니다. 레벨 상한·비용·교체 손실은 미정입니다.

손패 교환과 획득 카드 교체는 별도 행동으로 제안합니다. 전투 중 교환은 현재 활성 덱 8장의 인스턴스를 순환시키고, 획득 카드 교체는 기존 1장을 새 1장으로 바꿔 덱 구성을 변경합니다. 손패 교환의 후보 규칙은 선택한 1장을 대기열 뒤로 보내고 앞의 1장을 받는 것입니다. 이 순서·사용 조건은 아직 선택하지 않았습니다.

Q-10=A의 레벨은 개별 설치 타워의 상태입니다. 공통 장비는 해당 종류의 기존·신규 개체에 동일한 기준으로 적용하고 개별 레벨과 구분하는 안입니다. 룬은 후속 공격 방식 분기 역할이며 획득 비용·중첩은 미정입니다.

## 자원과 제작의 역할

- 출발 편성점수는 시작할 카드 조합의 예산입니다.
- 전투 에너지는 카드 사용·개별 타워 레벨·손패 교환 비용입니다. 행동별 가격·강화 상한은 미정입니다.
- 제작 광물은 도구·공통 장비에 사용합니다. 특수 제작법·지원 공격의 구체 비용은 후속 후보입니다.
- 금은 슬롯 상한 강화와 유닛 카드 3택1 모집에 사용합니다. 카드를 얻는 것과 실제 소환을 구분하며 소환은 전투 에너지·유효 배치·전장 슬롯을 검사합니다. 모집 자체는 필드 유닛 수나 슬롯을 늘리지 않습니다.
- 룬은 후속 공격 방식 분기로 역할을 정했습니다. 첫 연결판에는 구현하지 않고 획득·효과·중첩은 이후 설계합니다.

도구 등급에 따른 재료 접근과 제작 예시는 [채굴·제작 조사](mining-and-crafting-research.md)를 참고합니다. 카드 발견 조건·제작 조건·배치 조건은 구분해서 화면에 필요한 정보만 보여줍니다.

## 미정 항목

- 기본 4장과 선택 4장의 실제 구성, 편성점수·희귀도 환산, 같은 카드의 장수 상한.
- 발견 즉시 도감에 남길지와 승패·중도 종료 시 기록 범위.
- 건물 강화 상한·행동별 가격·교체 손실, 손패 교환 대상·순서·사용 조건.
- 일반 보상 넘김·모집 종류별 콘텐츠·성공 뒤 재모집·후보 만료, 여러 획득과 최근 카드가 다시 빠진 경우의 손패 우선 대상, 첫 손패 역할 보장.
- 맵 확장과 웨이브 보상이 겹칠 때의 보상 횟수·순서와 제시 후보 소진 처리.
- 금 강화 가격·상한·모집 종류별 콘텐츠·성공 뒤 재모집·교체 예외, 치료 재료·회복량·횟수, 무료 재배치의 유효 칸·퇴각·저지 수·적의 교전 우선순위.
- 특수 제작 카드의 출발 편성 가능 여부, 지원 슬롯과 일회용 충전 소모 규칙.

## 코드와 검증에 미치는 영향

읽기 전용 카드 정의와 한 판의 카드 인스턴스를 구분하고, 발견 도감·출발 편성·현재 덱 상태를 각각 다룹니다. 게임 규칙은 편성점수와 카테고리·사용 조건을 검사하고, 웹은 선택 UI와 저장을 연결합니다. 저장된 ID와 편성은 현재 콘텐츠 정의에 맞춰 검증한 후 시작합니다.

유닛은 C++ 전투 모듈에서 아군 상태와 표적 규칙으로 처리하고 렌더러는 에셋 키와 공개 상태를 받아 표현합니다. 기존 타워·탄환과 같은 시간·ID·이벤트 경계를 사용합니다.

우선 테스트할 항목은 시작 덱의 필수 카드·장수·점수, 미발견 카드 사용 거절, 시작 예산과 전투 코스트의 분리, 카드 보상 중복 지급 방지, 교체 후 덱 수·순환 보존, 새 판의 성장 초기화와 선택한 도감 기록 유지, 유닛 사망의 슬롯 반환과 웨이브 사이 개체·HP·슬롯 보존입니다. 아직 게임 코드는 생성하지 않았으며 이 문서의 세부 제안을 구현 승인으로 취급하지 않습니다.
