# 광물·금 재화·부대 정비 경제안

작성일: 2026-11-03. 재화로 쓰는 광물과 유닛 뽑기, 선택 치료·무료 재배치에 대한 사용자 답변을 반영했습니다. 금은 광물 이름의 가칭입니다. 금 모집의 카드 후보 3개 중 1개 획득도 선택했습니다. 수입·가격·후보 풀·상한은 확정과 제안을 구분하며 [결정 기록](decisions.md)의 D-36~D-39·D-44를 따릅니다.

## 선택한 방향

| 항목 | 확정한 내용 | 남은 결정 |
| --- | --- | --- |
| 제작 광물 | 첫 검증은 철·구리·수정 3종 | 광맥 위치·수확량·등급·레시피 |
| 재화 광물 | 금처럼 돈으로 사용하는 광물 도입 | 최종 명칭·획득량·광맥 배치·도구 등급 |
| 재화 사용처 | 슬롯 강화와 유닛 카드 3택1, 획득 시 기존 1장 교체 | 가격·단계·최종 상한·후보 종류별 콘텐츠·재모집 |
| 유닛 치료 | 정비 중 재료를 써 원하는 유닛 치료 | 재료 종류·양·회복량·횟수 |
| 재배치 | 정비 중 무료 위치 변경, 같은 개체·남은 HP·슬롯 유지 | 유효 배치 칸·자리 교환·퇴각 규칙 |

금은 모집으로 카드를 얻는 비용이고 실제 병력 소환은 전투 에너지를 사용합니다. 모집 자체는 전장에 유닛을 만들거나 슬롯을 차지하지 않습니다. 치료 비용을 금으로 통일할지는 아직 미정입니다.

## 자원의 역할 분리

| 자원 | 역할 | 적용 범위 |
| --- | --- | --- |
| 전투 에너지 | 카드 사용·개별 타워 레벨·손패 교환 | Q-06·Q-10 역할 확정, 회복·가격·상한 미정 |
| 제작 광물 | 도구·장갑·코일 등 레시피와 선택 치료 | 철·구리·수정 3종이 첫 검증 구성으로 확정 |
| 금(가칭) | 슬롯 강화·유닛 뽑기 | 채굴로 얻는 재화, 세부 수입·소비량 미정 |
| 출발 편성점수 | 시작 덱 조합의 예산 | 출발 시 검사하는 별도 제안 |

Q-14=A로 첫 검증의 자원을 철·구리·수정의 제작 3종 + 금 재화 1종으로 확정했습니다. 토륨은 후속 심층 자원 후보이며 첫 보드의 필수 재료가 아닙니다. Q-14의 다른 안은 비교 기록으로 보존합니다. 구성을 선택한 것이 도구 전체 등급·레시피·장갑 효과까지 확정한 것은 아닙니다. Q-10=A로 에너지는 개별 타워 레벨, 광물은 도구·공통 장비, 룬은 후속 공격 방식 분기로 역할을 정했습니다. 룬의 획득 비용은 미정이며 이전 광석 구매 가격을 가져오지 않습니다.

## 금 획득과 보관의 추천안

금 광맥을 캐면 해당 판의 금 잔액에 바로 더하는 방식을 추천합니다. 금광석 재고와 판매 후 골드 잔액을 동시에 만들지 않고 한 잔액으로 시작하는 안입니다. 제련·판매·환율을 넣을지는 후속 요구로 판단합니다.

기본 도구로 금에 접근하도록 하는 시작안을 제안합니다. 기본 광맥 수입과 슬롯·모집 가격을 함께 검증해야 합니다. 웨이브 보상으로 금을 추가 지급할지, 제작 광물을 팔 수 있게 할지는 미정입니다.

기존의 한 판 성장 초기화 방향에 맞춰 금 잔액·슬롯 강화·획득 병력은 이번 판 상태로 다룹니다. 영구 도감과는 별개이며 판 사이 화폐나 금 이자를 추가한 제안은 아닙니다.

## 슬롯 강화와 모집의 선택

같은 금으로 병력 상한을 늘릴지 새로운 유닛을 뽑을지 결정합니다. 기본은 6슬롯·첫 유닛당 1슬롯이고 생존 유닛은 슬롯을 계속 점유합니다. 강화로 상한만 늘리며 이미 있는 유닛의 ID·현재 체력·점유량을 초기화하지 않습니다.

6→8→10은 검토할 수 있는 단계 예시입니다. 가격·최종 상한·정비당 강화 횟수는 확정하지 않았습니다. 현재 슬롯에 빈자리가 많은 상황에서도 상한 강화만이 항상 최선이 되지 않는지 비교합니다.

### Q-23의 모집 결과 선택 기록

| 안 | 얻는 것 | 전투와의 연결 |
| --- | --- | --- |
| A | 금으로 유닛 카드 후보 3개 중 1개 선택 | 덱 교체·발전, 실제 소환은 기존 전투 에너지 사용 |
| B | 금으로 무작위 유닛 카드 1장 획득 | 덱 교체·발전, 중복·결과·순환 규칙 필요 |
| C | 금으로 실제 유닛을 즉시 모집 | 전장 슬롯 사용, 일반 카드 소환과의 관계를 다시 정함 |

사용자가 A를 선택했습니다. 후보 수 3과 그중 1장 획득, 실제 소환의 전투 에너지 사용을 확정합니다. 필드 슬롯이 가득 차도 모집 자체는 새 슬롯을 사용하지 않습니다. 획득 시 기존 1장과 교체해 활성 덱 8장을 유지하고 다음 공세 손패를 재구성해 최근 획득 1장을 우선 포함합니다. B·C는 비교 기록입니다.

덱 8장·1대1 교체·정비 후 최근 획득 우선 손패 재구성은 확정입니다. 금 모집 후보 확인은 무료이며 새 카드와 기존 카드의 교체를 확정할 때 결제합니다. 취소는 무소모이고 다시 열어도 같은 후보를 유지합니다. 횟수·가격·성공 뒤 재모집·모집 기회 만료·일반 보상 넘김과 여러 획득 예외는 Q-14·Q-20에서 정합니다. 보관함이나 덱 장수 증가는 현재 선택하지 않았습니다. 유효 후보 3개를 구성하지 못하면 금을 소모하지 않고 모집 불가 이유를 표시하는 안을 권장합니다. 후보 선택·교체 확정 전까지 덱과 금을 바꾸지 않고 확인 시 현재 잔액을 다시 검사하는 안입니다. 잔액 부족은 금·덱·후보를 보존합니다.

첫 모집 풀은 경비병·사수·폭파병 3종을 후보로 둡니다. 세부 능력·코스트는 미정이며 사용자 확정 제작 목록은 아닙니다. 보유 종류도 후보에 포함하고 제시 3종은 서로 다르게 구성합니다. 이 3종으로 시작하면 같은 세 종류를 제시하므로 더 큰 풀의 종류 추첨은 후속 검증입니다. 기존 유닛 1종·전체 6종 예시는 이 선택을 검증하기에 부족해 프로토타입의 8종 후보안으로 확장했습니다.

## 선택 치료와 재배치

정비에서 유닛 하나를 고르고 재료를 지불해 치료합니다. 필요한 재료·회복량을 먼저 보여주고 죽은 유닛의 부활이나 슬롯 확대와 구분합니다. 체력이 가득 찼거나 대상이 없으면 비용을 소모하지 않는 안입니다. 치료는 최대 체력을 넘지 않아야 합니다.

재배치는 정비 중 무료이며 기존 유닛의 위치만 변경합니다. 유효한 새 배치 칸을 선택하고 같은 EntityId·현재 HP·점유 슬롯을 유지합니다. 이전 자리를 먼저 비운 뒤 새 자리에 놓지 못하는 부분 변경을 만들지 않습니다. 자리 교환·겹침 허용 여부는 배치 규칙과 함께 정합니다.

장갑이 최대 체력을 올리는 경우 기존 HP는 그대로 두고 치료를 별도 동작으로 하는 안을 추천합니다. 장갑의 효과와 기존 HP 반영 수치는 아직 선택하지 않았습니다. 새 소환·재배치·장갑 제작이 무료 완전 치료로 바뀌지 않는지 확인합니다.

## 5굴착 정비와 경제 검증

금 광맥은 제작 재료와 같은 굴착 예산을 사용하므로 기존 보드에 금을 얹고 예전 진행 가능성 결과를 재사용하지 않습니다. Q-16=A로 선택한 수작업 보드 1개에서 다음을 함께 계산하고 자동 생성은 후속으로 둡니다. [첫 보드·경제 초안](first-board-economy.md)에 네 예시 경로의 접근·작업 수·재고 계산을 검증했습니다. 공개 정보로 경로를 찾을 수 있는지와 실제 전투 균형은 아직 검증하지 않았습니다.

1. T1으로 T2 재료를 확보하고 다음 정비에서 수정의 방어 용도에 접근 가능함.
2. 금 탐색도 선택할 수 있고 금이 필수 도구 재료를 무조건 대체하지 않음.
3. 슬롯 강화와 뽑기 사이에 선택 이유가 있으며 하나가 항상 우월하지 않음.
4. 치료에 재료를 사용해도 다음 필수 진행이 막히는지 예측 가능함.
5. 생존 병력·남은 HP·슬롯을 유지하는 이점과 투자 비용이 공세 난이도에 반영됨.

수입·광맥 배치·가격·뽑기 풀·회복량은 P0 수치표에서 정합니다. 전체판이나 첫 연결판의 균형을 검증한 상태는 아닙니다.

모집 성공 1회/정비·미구매 후보의 정비 종료 만료, 고정 비용 치료·정비 해산·장비 효과는 [플레이 사양 P-04·P-07](first-playable-spec.md)의 추천안으로 정리했습니다. 기존 금 결제·취소 선택은 유지하고 새 횟수·효과·해산 규칙은 검토 대기입니다.

## 상태와 검증 경계

RunState에는 제작 재고와 금 잔액을 구분하는 안을 권장합니다. 채굴 결과가 둘을 동시에 중복 지급하지 않게 하고 같은 잔액을 웹과 C++에 각각 따로 소유하지 않습니다. 슬롯 강화·뽑기·치료·재배치는 정비 단계의 명령으로 검토합니다.

- 금·재료 부족이나 잘못된 대상에서는 잔액·상한·유닛을 바꾸지 않음.
- 유효한 강화·치료는 비용과 결과를 한 번 적용함.
- 모집은 후보 3개 중 1개 카드 획득으로 반영하고 금·카드를 한 번 처리하며 취소·교체·중복을 검증함.
- 모집 자체는 전투 에너지·필드 개체·사용 슬롯을 바꾸지 않고 실제 카드 사용만 유효 배치·비용·슬롯을 검사함.
- 무료 재배치가 금·재료를 소모하거나 새 유닛 생성·HP 초기화를 일으키지 않음.
- 치료 후 HP 상한, 웨이브 사이 병력·HP·금·슬롯 성장 유지, 새 판 초기화를 검증함.

2026-11-13에 구현한 수정·금 사용처(T3 드릴, 건물 각성, 광부 고용, 보급 상자)는 [정비 자원 사용처](../economy-sinks.md)에 있습니다. 이 문서는 게임 로직 구현이 아닌 계획입니다. 개별 선택지는 [규칙 문서](rule-options.md), 구조는 [아키텍처](architecture.md), 실제 테스트 계획은 [검증 계획](validation-plan.md)에 연결합니다.
