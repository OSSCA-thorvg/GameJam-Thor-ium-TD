# 결정 및 미정 사항

기준일: 2026-11-03. 규칙의 확정 상태는 이 문서를 기준으로 관리합니다. 대화에서 나온 예시나 제안을 구현 요구사항으로 자동 승격하지 않습니다.

2026-11-03 사용자가 승인한 작업은 서브에이전트 조사와 선택지·아키텍처 문서 정리입니다. 아래 개별 게임 규칙이나 게임 골격 구현을 일괄 승인한 것으로 취급하지 않습니다. [시작 계획](preproduction-plan.md)과 [규칙 선택지](rule-options.md)에서 검토합니다.

2026-11-04 사용자가 첫 구현을 명시적으로 승인했습니다(D-63). SDL·ThorVG·공통 UI와 3웨이브 시연판의 실제 범위·검증은 [첫 구현 기록](implementation-v0.1.md)에 따릅니다. 기존 실험 수치를 시연판에 사용한 것과 모든 기획 규칙의 최종 확정은 구분합니다.

## 상태 기준

| 상태 | 의미 |
| --- | --- |
| 확정 방향 | 사용자가 명시했거나 실제 등록 이슈에서 확인한 정체성·방향 |
| 검토 방향 | 사용자가 관심을 표현했고 기획에 반영을 검토하는 요소 |

남은 운영 규칙과 초깃값은 [첫 3웨이브 플레이 사양](first-playable-spec.md)의 P-01~P-10에 한 묶음으로 제안합니다. D-59는 실험안이며 이 문서의 기존 확정 답변을 바꾸거나 새 제안을 사용자 선택으로 승격하지 않습니다. 아래 질문의 남은 항목에도 추천안이 준비되어 있고 채택 여부·실제 플레이 검증은 별도입니다.
