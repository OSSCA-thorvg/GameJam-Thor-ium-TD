# 튜토리얼 구성안

2026-11-08 사용자가 **별도 연습 원정 + 정규 원정의 상황별 힌트**를 선택했습니다. 2026-11-09 첫 구현 범위인 별도 연습 원정의 7단계·건너뛰기·체크포인트 재시도·재시작을 연결했습니다. 정규 원정의 상황별 힌트는 아래 표를 기준으로 이어서 구현할 범위입니다. 첫 목표는 조작법 암기보다 **카드로 방어하고 → 채굴한 자원으로 다음 방어를 준비하는 게임**이라는 이해입니다.

## 진입과 범위

처음 메인 화면에서 `연습 원정`을 안내하고 `바로 원정 시작`도 제공합니다. 연습은 첫 전투와 첫 정비를 3~4분 정도 체험하는 짧은 별도 판으로 구성합니다. 건너뛰기와 메인 화면으로 돌아가기를 항상 제공하고, 플레이 방법 화면에서 다시 시작할 수 있게 합니다. 정규 원정의 첫 판을 강제로 튜토리얼로 바꾸지 않습니다.

시작 시에는 “지상에서는 카드로 거점을 지키고, 전투가 끝나면 지하를 채굴해 다음 방어를 준비해요. 마지막 웨이브까지 거점이 살아남으면 승리예요”라는 두 문장과 거점·지하 방향을 보여줍니다. 현재 정규 원정은 3웨이브이며, 연습은 이 흐름 중 첫 전투·첫 정비를 경험합니다. 카드 순환·모집·슬롯·둥지·확장을 한 화면에서 모두 설명하지 않습니다.

## 연습 원정의 순서

| 단계 | 강조할 화면 | 플레이어가 할 일 | 완료 판정과 안내 문구 예시 |
| --- | --- | --- | --- |
| 1. 거점과 에너지 | 거점, 손패 바로 아래 에너지 바 | 게임 목표와 시작 에너지 6 확인 | 짧은 확인 후 진행. “거점의 체력이 0이 되기 전에 적을 막아야 해요. 이 에너지로 카드를 사용해요.” |
| 2. 첫 건물 배치 | 연사탑 카드, 추천 패드 1곳 | 카드를 드래그해 범위를 확인하고 패드에 놓기 | 실제 연사탑 생성 확인. “카드를 끌면 공격 범위가 보여요. 초록색 패드에 놓아 보세요.” |
| 3. 비용과 유닛 | 줄어든 에너지, 경비병 카드, 추천 유닛 칸 | 남은 에너지 3으로 경비병 배치 | 실제 유닛 생성과 에너지 지출 확인. “건물은 멀리 공격하고, 유닛은 길 위에서 적을 막아요.” |
| 4. 전투와 순환 | 거점 방향, 새로 들어온 카드 | 소규모 공세를 관찰하고 전투 마치기 | 정상 웨이브 종료. “사용한 카드는 덱 뒤로 돌아가고 다음 카드가 들어와요.” |
| 5. 첫 채굴 | 지하 전환, 무료 스캔, 굴착 횟수 | 안전한 칸 스캔 → 타일 선택 → 광부의 이동·굴착 확인 | 실제 스캔 소모, 굴착 완료, 광물 지급 확인. “스캔은 정보만 보여줘요. 광부가 캐야 재료를 얻어요.” |
| 6. 도구 제작 | 철·구리 수량, T2 곡괭이 버튼 | 안전한 경로를 따라 재료를 모으고 T2 제작 | 실제 재료 차감과 도구 등급 상승 확인. “채굴한 재료로 더 깊은 곳을 캘 수 있어요.” |
| 7. 다음 투자 | T2 지층, 금, 모집·슬롯 버튼 | T2 광물 1칸을 캐고 다음 투자 선택 이해 | 금 획득 후 연습 완료. “금으로 카드를 모집하거나 부대 슬롯을 늘릴 수 있어요.” |

연습 원정의 에너지·비용·카드 효과·굴착·제작은 실제 규칙을 사용합니다. 첫 두 배치가 끝날 때까지 적은 출현하지 않도록 진행을 제어하고, 이후에는 짧은 연습 공세를 진행합니다. 전투 중 자동으로 주인공을 무적 처리하거나 에너지를 무한히 주는 방식은 사용하지 않습니다.

현재 기본 채굴 보드와 가격을 사용하면 `6 → 7 → 11 → 12`의 네 안전 굴착으로 철 4·구리 4를 모아 T2를 제작하고, 다섯 번째 굴착 `13`으로 금 4를 얻는 경로를 활용할 수 있습니다. 숫자·셀 ID는 내부 시나리오 데이터이며 플레이어에게는 타일 강조로 안내합니다. 연습 데이터가 바뀌면 이 공개 명령 경로의 실행 가능성도 다시 검사합니다. 첫 굴착만 자세히 설명하고 반복 굴착은 짧은 안내로 줄입니다.

연습 종료 시 `정규 원정 시작`과 `메인 화면`을 제공합니다. 연습 판의 광물·배치·덱을 정규 판으로 이월하지 않고 기본 시작 덱으로 시작한다는 점을 종료 화면에서 알려줍니다. 설정과 연습 완료 기록은 판 상태와 별도로 관리하는 방향입니다. 영속 저장 방식은 후속 설계 대상입니다.

## 정규 원정의 상황별 힌트

각 힌트는 해당 상황을 처음 만났을 때 한 번만 짧게 표시합니다. 행동을 강제하거나 정규 전투를 매번 멈추지 않습니다.

| 발생 상황 | 안내 |
| --- | --- |
| 같은 종류의 건물 카드가 다시 들어오고 기존 타워가 있음 | “같은 건물에 놓으면 강화돼요. 실제 비용은 대상을 가리키면 보여요.” |
| 다른 건물로 교체할 수 있는 패드를 가리킴 | “교체하면 기존 강화가 사라지고 새 건물이 설치돼요.” |
| 에너지가 부족한 카드를 시도함 | 하단 에너지 바를 잠깐 강조하고 실제 부족 사유 표시 |
| 처음 배치한 대상을 클릭함 | 사거리와 철수 버튼 안내. 철수 시 비용 반환이 없음을 확인창에서 설명 |
| 첫 부상 유닛으로 정비에 들어옴 | 남은 체력 유지, 재료 치료, 무료 위치 변경 안내 |
| 처음 공개된 지하 숫자를 봄 | “주변 8칸의 최초 둥지 수예요. 숫자가 공개돼도 채굴은 별도로 해야 해요.” |
| 둥지를 실제로 굴착함 | 다음 공세 추가 적 예약·예고를 강조 |
| 처음 금을 얻음 | 슬롯 강화와 유닛 카드 3택1 모집의 선택을 설명 |
| 처음 모집 후보를 열음 | 후보 확인 무료, 기존 카드 교체 확정 시 결제, 활성 덱 8장 유지 안내 |
| 2웨이브 후 확장이 열림 | 두 경로의 차이를 설명하고 실제 확장·보상 선택 안내 |

정규 원정의 힌트는 이미 공개된 정보와 실제 사건을 사용합니다. 숨은 둥지 위치나 광물 정보를 힌트로 먼저 공개하지 않습니다.

## 안내 표현과 실패 복구

- 한 번에 대상 하나와 1~2문장만 강조합니다. 선택 영역의 테두리·화살표·실제 범위 원을 함께 사용합니다.
- 마우스와 터치 모두 가능한 `선택하거나 끌어 놓기`를 기본 표현으로 사용합니다. 드래그 자체를 연습하는 단계는 실제 이동 후 놓기까지 확인합니다.
- 잘못된 위치에 놓으면 기존 빨간 표시와 규칙의 실패 문구를 사용합니다. 비용·진행도는 실패로 소모하지 않습니다.
- 잘못 배치한 경우 재배치·철수 안내 또는 현재 연습 단계 다시하기를 제공합니다. 자원을 다 써서 정답 배치를 할 수 없으면 연습 체크포인트를 복구하여 막히지 않게 합니다.
- 읽는 동안 필요한 설명 단계만 시뮬레이션을 멈춥니다. 포인터 이동·드래그·툴팁은 계속 작동해야 합니다.
- 건너뛰기·뒤로 가기·다시하기와 모바일의 안내창 위치를 명시적으로 지원합니다. 화면 크기가 바뀌면 강조 위치를 다시 계산합니다.

## 구현 경계 제안

`TutorialDirector`를 앱 계층에 두고 현재 단계·강조 대상·안내 문구·시뮬레이션 대기 여부를 관리하는 안을 추천합니다. `Run`에 단계별 튜토리얼 분기를 넣거나 렌더러가 카드 ID별 진행을 결정하지 않습니다.

연습 맵·공세·시작 덱은 검증된 별도 `Catalog`/시나리오 데이터로 구성하고, 배치·굴착·제작은 기존 공개 명령을 사용합니다. 단계 완료는 클릭 여부보다 실제 개체·자원·도구·웨이브 상태 또는 성공한 명령 결과로 판정합니다. `FeedbackChannel`이 수거하는 이벤트 큐를 튜토리얼이 두 번째로 소모하지 않습니다.

튜토리얼의 “설명을 위해 시간만 멈춤”은 일반 일시정지와 분리해야 합니다. 현재 `paused`는 배치 입력도 막으므로, 이 값을 그대로 쓰면 “멈춘 상태에서 카드를 놓아 보세요”를 수행할 수 없습니다. 앱에서 시뮬레이션 허용 조건과 단계별 입력 허용 조건을 명시적으로 조합하고 화면도 같은 조건을 사용하도록 합니다.

표현 계층은 튜토리얼의 추상 강조 대상(에너지 바·카드·패드·굴착 타일)을 현재 `Layout`/위젯의 좌표로 바꿉니다. 320px, 크기 변경, 설정 복귀 후에도 같은 논리 대상을 강조합니다.

## 구현 전·후 검증 항목

1. 공개 명령만으로 에너지 6 → 연사탑 3 → 경비병 3 → 정상 웨이브 종료 → 5굴착 → T2·금 획득이 완주 가능한지 확인합니다.
2. 스캔만 하거나 잘못 놓거나 단순히 클릭한 것만으로 다음 단계로 넘어가지 않아야 합니다.
3. 안내 대기 중 시간은 멈추지만 드래그·범위 미리보기는 작동해야 합니다.
4. 에너지 부족·잘못된 카드 순환·철수·연습 중 이탈 후에도 복구·건너뛰기가 가능해야 합니다.
5. 완료·재시작·건너뛰기·설정 방문 시 정규 판, 연습 판, 세션 설정과 완료 기록의 수명을 각각 확인합니다.
6. 마우스·실제 터치·320px 화면에서 강조·안내·버튼이 서로 가리지 않는지 확인합니다.

첫 구현 범위는 별도 연습 원정의 일곱 단계와 건너뛰기·재시작입니다. 정규 원정의 상황별 힌트는 위 목록을 우선순위에 따라 이어서 붙이는 안입니다. 사용자의 방식 선택은 확정됐으며 세부 단계·문구·시나리오 수치는 구현 전 조정할 수 있습니다.

## 첫 구현 기록 · 2026-11-09

- 메인과 플레이 방법 화면의 `연습 원정`에서 진입합니다. 완료 후 메인에서는 다시 연습할 수 있습니다.
- [TutorialDirector](../src/app/TutorialDirector.h)는 단계·입력 허용·설명 중 시뮬레이션 정지·체크포인트를 관리합니다. `Run`의 규칙에 튜토리얼 조건을 추가하지 않았고, 기존 이벤트 큐도 다시 소비하지 않습니다. 설명 중에도 마우스·터치 드래그, 실제 사거리 미리보기, 카드 정보창이 동작합니다.
- [연습 카탈로그](../src/game/content/TutorialCatalog.cpp)는 검증된 별도 데이터입니다. 첫 공세는 일반 적 4명이며, 첫 배치 두 개가 끝나야 시뮬레이션이 진행됩니다. 기존 전투·에너지·도구 비용을 그대로 사용합니다. 첫 공세 후 정비를 만들기 위한 다음 웨이브 데이터는 실제로 시작하지 않습니다.
- `6 → 7 → 11 → 12`의 안전 경로로 철 4·구리 4를 모읍니다. 연습 보드만 13번 금 타일을 T2 지층으로 설정해, 제작 후 다섯 번째 굴착에서 금 4를 얻도록 했습니다. 정규 보드의 데이터는 유지합니다.
- [표현 UI](../src/game/presentation/TutorialUi.cpp)는 현재 레이아웃에서 카드·에너지·추천 배치 칸·채굴 타일을 찾습니다. 설명과 조작은 사이드바에 배치하고, 작은 화면의 지하 영역은 확대해 안내 패널과 분리합니다. 내부 단계는 스캔과 첫 굴착을 분리하지만 화면에서는 같은 5/7단계로 표시합니다.
- 실제 개체 생성·에너지 지출·스캔 소모·광부 작업 완료·광물 지급·도구 제작·금 획득을 확인합니다. 안내 버튼만 누르거나 스캔만 해서 굴착 단계를 건너뛸 수 없습니다.
- 잘못된 일반 배치는 기존 규칙으로 거절합니다. 추천 위치가 아닌 유효한 칸에 연습 대상을 놓으면 해당 단계의 체크포인트를 복구하고 이유를 알립니다. `다시하기`는 현재 단계 시작으로, 완료 화면·플레이 방법의 연습 시작은 처음으로 돌아갑니다.
- 정규 원정의 판·상호작용·애니메이션 상태를 잠시 보관합니다. 건너뛰기·메인 이동 시 보관한 판을 복구하고, 설정과 이번 앱 세션의 연습 완료 기록은 유지합니다. 완료 후 정규 원정을 새로 시작하면 연습 자원·도구·배치가 이월되지 않습니다. 기존 정규 원정이 있다면 기존 새 원정 확인 절차를 따릅니다. 파일·브라우저 저장은 추가하지 않았습니다.
